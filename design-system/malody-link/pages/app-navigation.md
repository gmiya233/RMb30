# 首页 / B30 / 设置

沿用现有深蓝背景与原生系统字体。移动端覆盖规则：强调色使用浅青绿 `#74E4D6`，卡片 `#19263B`，主要文字 `#F1F5F9`，次要文字 `#B1BFD2`。不采用数据库建议中的网页营销模块、像素字体或闪烁装饰。

- 底部固定三项导航：同一套 24 单位线框图标＋文字、选中底色和原生涟漪反馈。最小触控 48dp，栏本身至少 64dp。
- 外层布局统一处理系统安全区。内容和导航分配各自的布局高度，避免悬浮遮盖；首页、设置独立记住滚动位置，返回键先回首页。
- 首页：成绩概览、同步入口、实际 B30 缩略图、按游玩时间倒序的最近十条有效成绩。图片异步生成并预留尺寸，不补造示例成绩。
- B30：直接嵌入原生成绩图，不切离导航。保存相册与调整菜单放在上方；图片完整适配剩余区域，支持原有双指缩放和复位。
- 设置：云存档、读取授权、谱库、导入导出、版本。将首次设置和次要管理操作移出首页。
- 正文使用系统字体和 sp，按钮按内容自然增高。内容在平板居中限宽 760dp，无装饰动画，兼容关闭系统动画。
