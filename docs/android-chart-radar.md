# Android 谱面六维（1.6.21）

入口：歌曲 → 歌曲详情 → 对应难度的「谱面六维」。本次只实现安卓；不修改战力榜、rating 规则或 iOS。

## 视觉和交互

- 保留第一套街机霓虹视觉；按用户在字体聊天中选择的 B 方案，中文用 Noto Sans SC，英文与数字用 Rajdhani SemiBold／Bold。
- 顺时针：物量、同押、爆发、变速、长按复合、滑键。变速位于正下方。
- HELL 只放在对应维度名称旁，使用深红描边框。按 `Paint.getTextBounds` 的实际字形边界计算双向居中，不以字体行高估算。
- 进入时仅数据多边形从中心展开，700ms 减速动画；支持重播、双指缩放、拖动与双击缩放。系统关闭动画时直接显示完整图。
- 整页深色，说明放入信息按钮；返回、信息、保存、重播、缩放均使用线框图标。顶部按钮48×48dp，底部56×56dp，长按显示说明。
- 保存通过相册API导出完整最终图，1240×2200 PNG，不取动画中间帧。

## 当前数据范围

`android/assets/chart-radar.json` 是2026-10-30只读谱库快照的派生数据：313张10～15级谱面，其中46张原始IMD的变速为0。不是玩家能力统计，也不下载或修改Malody文件。

刻度使用同键数、该轴前五均值为100的候选标定。等级参考框沿线性方案取 `10×折算等级−40`：12级80、13级90、14级100，10／11／15级为60／70／110。原始六维刻度不变，HELL表示超过该等级框；绘图区之外使用箭头和真实数值。

数据必须匹配当前服务器、CID、谱面hash、键数与折算等级。未分析或内容／定级已变化的谱面明确提示等待更新，不用其他谱面的数据代替。本版没有部署增量六维计算服务；新增谱面需要后续更新派生数据。

## 字体与复现

字体随APK内置，原始SIL OFL许可证在 `android/assets/licenses`，字体来源和摘要见 `android/assets/radar-fonts/README.txt`。旧字体对比使用的下载缓存位于忽略目录 `assets/fonts/radar-preview`，按需由 `tools/render_font_comparison.py` 下载，避免重复提交大字体。

构建：`python -B tools/build_android.py`；真机测试包：`python -B tools/build_android.py --test-apk`。保持所有依赖、缓存和产物位于E盘。
