# Rating v3：C 判 99.8% 整数基准

单曲 rating = 折算等级 × ACC 系数 × 判定倍率。

| 判定 | 倍率 |
|---|---:|
| A | 0.97 |
| B | 0.985 |
| C | 1.00 |
| D | 1.02 |
| E | 1.04 |

准度以百分数 P 表示：

- P < 99.5：`(P / 99.5)^2 / 1.01`。
- 99.5 ≤ P < 99.8：`[1 + (P - 99.5) / 30] / 1.01`。
- 99.8 ≤ P ≤ 100：`1`。

原始等级转换、SC 优先级、同歌曲去重、O20/N10 容量及缺位分母保持原规则。99.8%～100%封顶不变。14级在99.8%时A/B/C/D/E分别为13.58/13.79/14/14.28/14.56；同等级A99高于E95，E95介于C96.5与C97。
