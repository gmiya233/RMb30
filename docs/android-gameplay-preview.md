# 安卓自动游玩预览（1.6.27 原轨道素材校准版）

歌曲详情的每个难度可打开「自动游玩预览」。横屏舞台沿用用户提供的 EX Rhythm Master VI 音符素材，以近宽远窄的轨道、侧框、底部琴键和曲绘背景展示谱面；自动命中显示演示判定和连击，不产生玩家成绩。

## 读取顺序

1. 复用已有内置本机读取连接，只在 Malody chart 目录中按文件名和谱库身份匹配 MC。优先尝试同目录中与 MC 文件名或歌名精确对应的 IMD；有多个匹配 MC 时转为服务器读取，避免任意选取。
2. 音乐从同目录读取，最多32 MiB。只新增 MC/IMD 与 ogg/mp3/wav/m4a 的只读能力，不修改原谱面、音乐、成绩或回放。
3. 本机无法读取时，通过现有 Rank1 通道读取 `/_chart_previews/v1/playback/<CID>.json`。校验 server/CID/server_hash，音乐按 SHA256 和字节数核验。服务器输出派生时间线，不向客户端提供部署凭据或源目录。
4. 无法取得音乐时允许静音预览并明确提示。本地谱面成功但音乐缺失时保留本地谱面，不以服务器版本替换。临时音乐在关闭预览时清理。

## 播放和流速

- 播放、暂停、重新开始、拖动进度；音乐丢失音频焦点或 App 进入后台时暂停。
- 流速滑杆0.5×至12×，记住上次设置。1×对应默认两秒下落距离；调节流速不改变音乐播放速度。
- 播放和拖动进度后与音乐对时，帧间由单调时钟推进，避免每帧音频缓冲时间戳跳动影响画面速度。BPM 表用于拍号到秒的转换，避免将 BPM 变化误当作整个舞台突然加减速。
- 默认按固定屏幕像素/秒下落，音符中心间距由时间固定；纹理按原皮肤的宽高比例等比缩放；不施加额外斜切。透视不会改变纵向运动。开启「谱面变速」后，MC的显式hs/scroll事件才按积分距离影响下落速度。支持0至32倍的非负谱面流速；反向/极端流速、中途停顿、多音轨暂不支持，显示不可用；皮肤 Lua、复杂视觉脚本不会执行。
- IMD 使用原毫秒时间。开头音频偏移独立处理，不当作中途停顿。MC 分段的时间和横坐标相对音符头，滑键在节点时水平换轨。
- 播放两秒后隐藏控制栏；点舞台可显示/隐藏。滑杆拖动时保持控制栏可见。

## 服务器

`server/chart_preview/autoplay.py` 由现有只读预览发布服务调用。输出位于同一预览目录的 playback 子目录，音乐按内容摘要去重，优先硬链接，跨文件系统则复制；不 chmod 或写入源音乐。每次先比较源文件元数据和谱库版本，变化后重建时间线。原静态图的缓存和机器人接口保持可用。

当前服务器447张谱面中433张已生成动态时间线，包括6K New Astronomas（1358个音符、77条流速事件）；14张暂不可用。此为当前数据快照，目录会继续更新。

## 验证

- Java核心检查：BPM换算、MC音频偏移、相对滑键坐标、IMD长按时间、中途停顿拒绝、恒速与显式流速积分。
- Python新增2项发布测试：派生时间线与音乐摘要、增量缓存、变更后撤销旧可用状态及路径越界拒绝；原静态预览9项测试通过。
- 已在vivo加载4K IMD服务器谱面与原曲，确认播放画面和拖动功能。横屏参考版仍需完成真机检查；本机优先分支需在无线读取连接可用时验证。未使用电脑模拟器。

这是一版按谱面数据实现的预览器，不是完整的 Malody/RM 游戏运行时。所有AUTO判定仅供观看，未复现游戏计分、道具或皮肤脚本。

## 1.6.26 离线核对

从用户手机中只读提取的 RM VI 250314 脚本确认：实际入口是 `rmslideEXF.lua`。脚本的 `OnNoteMove` 接收 Malody 提供的进度p，先用立方映射得到绘制进度，再计算坐标。尚未验证引擎如何生成p，不能声称已取得正版节奏大师源码或直接把该立方映射应用到剩余秒数。预览器以自己的秒时间线保持恒速，未再次套入此映射。

已提取的几何事实：远端缩放为25.9/210；轨道总宽1680；4K/5K/6K音符逻辑宽406/337.8/290，逻辑高116。这些用于横向透视和纹理比例，纵向中心仍由固定像素/秒计算。Lua原文、安装包和设备目录快照只保存在忽略的build目录中，不随源码或APK发布。

新增纯Java轨迹测试在720/1080/2400高视口及0.5/1/2/6/12倍流速下检查1500组位移，验证中心恒速、相同时间间隔的纵向间距、判定线对齐与皮肤宽度比例。另生成离线合成谱面视频，使用Java实际几何坐标，不是Android模拟器或真机录屏。1.6.26需后续真机核验，当前可断开USB继续开发。

## 1.6.27 参考画面对齐

上一版离线演示错误地在6条轨道上都用了6note1，导致右侧音符也朝左倾斜；App本身虽逐轨选图，又对已带透视的原贴图做了一次额外四点变形。两者均已修正，演示和App都逐轨使用6note1～6原贴图，按原逻辑宽高比矩形缩放。

轨道框直接使用此前已提取的原皮肤图片1712474142416.png（2200×1200），移除手绘侧框和不一致的轨道填充。根据用户1920×864参考截图校准可见范围：顶部Y为1.5%，判定线73.5%，琴键底84.6%，判定线轨道半宽31.25%，可见远/近宽约0.2067。原Lua的0.1233对应未裁切空间，不能直接当作屏幕可见远端比例。

离线演示改为与参考相同的1280×576比例，中心仍由单调时钟恒速推进。恒速回归与参考边界、各键数贴图比例检查通过。原轨道素材仅覆盖轨道和框体，底部按键仍按参考几何绘制；未取得完整键盘底图，不声称完整游戏界面已逐像素复刻。真机尚未验证。
