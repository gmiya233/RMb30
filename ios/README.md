# Malody Link iOS 0.1.0 测试说明

适用于 iOS / iPadOS 16 及以上的 Malody V 玩家。测试包是原生 arm64 **未签名 IPA**，需要测试者使用自己的自签工具签名安装，不能直接点击 IPA 安装。Android 安装包不能用于苹果设备。

## 首次使用

1. 安装并打开 Malody Link。在首页选择「Malody V」根文件夹：它里面应该同时有 `chart` 和 `replay` 两个文件夹。不要只选择 `replay`。
2. 点击「同步本机成绩」。App 读取 `.mc` 和 `.mrv`，只导入服务器谱库中匹配的歌曲，保留本地成绩。不会修改或删除 Malody 原文件。
3. 检查首页最近成绩与 B30。完整游玩一首歌，返回 Malody 选歌页面，再到本 App 同步，检查是否新增成绩。连续同步不应产生重复记录。
4. 关闭 App 后重新打开，再同步一次，验证文件夹授权能否保留。如果系统不允许选择 Malody V 根目录，或重新启动后无法读取，请把具体提示反馈给开发者。
5. 需要云端成绩时，在设置填写自己的 QQ 并保存，再手动点击云端同步。同 QQ 的本机与云端成绩会合并；请勿填写其他玩家的 QQ。

## 测试重点

- 最近成绩的原始分数、准确率、判定与 Malody 结算是否一致；`judge` 字段的判定含义还需要真机核对。
- 普通歌曲进入 O20，promote 新歌进入 N10；单曲最佳按 rating 计算，空位按 0 参与固定分母平均。
- SC 与 MaV 等级映射是否符合 Android 版本；歌曲信息页是否匹配。
- B30 预览、放大、分享／保存图片，以及横竖屏、iPad 显示。
- 排行榜使用服务器发布的 v2 快照，上传后需等待服务器下一轮生成；旧快照会标记时间。尚不支持旧版 v1 榜单。

## 当前范围与隐私

此版通过系统文件夹授权读取 `chart` 和 `replay`，不解析 `score.bin`，也不读取 Malody 账号配置或 Cookies。根目录中单独放置的回放暂不参与扫描，请使用 Malody 标准 `replay` 目录。

上传由玩家手动发起，遵循现有 QQ 成绩存档格式。昵称、称号、文件夹授权不上传；头像自定义暂未移植。本版未实现 Android 所有功能。

有问题时，可在设置导出诊断并连同错误截图反馈。诊断不包含 QQ、昵称、文件路径、密码或完整回放，但包含少量成绩数值与谱面 ID。无需发送整个 Malody 文件夹。

模拟器测试使用生成的虚拟谱面与回放，仅验证导入、去重、导航和预览。跨 App 文件夹授权能否长期保留、自签安装与真实游戏判定仍需苹果真机测试。更新请尽量保持相同签名和 Bundle ID；卸载可能导致本地存档和授权丢失。

## 构建

GitHub Actions 在 macOS 上运行 `swift test --package-path ios`、Xcode 真机 Release 构建和模拟器 UI 测试。运行时资源从已有 Android 发布包提取，不将账号凭据或玩家原始样本提交到仓库。IPA 打包前检查 iPhoneOS 平台、arm64 可执行文件与 Debug 测试夹具排除情况。
