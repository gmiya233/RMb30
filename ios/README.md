# Malody Link iOS 0.2.0

适用于 iOS / iPadOS 16 及以上。原生 arm64 未签名 IPA 需要用自己的签名工具安装。保留原 Bundle ID 和签名身份可覆盖更新。

## 首次导入

1. 设置页最上方点击「选择 Malody V 文件夹」，授权同时包含 `chart` 和 `replay` 的根文件夹。
2. 首页点击「同步本机成绩」。只读取与当前服务器谱库匹配的 `.mc`、`.mrv` 和曲绘，不修改游戏文件。
3. 如果系统没有开放 Malody 目录，可用电脑复制 `chart`、`replay` 到同一文件夹，通过 iCloud Drive 授权这个副本；副本需要自行更新。
4. 在设置填写自己的 QQ。不同 QQ 的本地存档分开保存；首次绑定会合并未绑定记录。默认导入后自动同步云端，可关闭。

iOS 不使用无线调试、USB 调试或 Shizuku。目录能否直接授权取决于游戏是否向「文件」App 开放目录，需苹果真机核对。

## 与 Android 同步的功能

| 页面 | 功能 |
|---|---|
| 首页 | 实际 Rating、O20/N10、R50 最近50次有效游玩，保留同曲多次记录；Rating 模拟 |
| B30 | O20/N10 成绩图、头像与称号、键数、放大、保存/分享、示例布局、绿色服务器上传按钮 |
| 歌曲 | 1–5列卡片（默认3列）、曲名/歌手/谱师/等级/键数搜索、隐藏未定级歌曲 |
| 详情 | 复制曲名图标、谱面键数与下载量、单谱排行榜、1–5星评论、最近50条评论 |
| 排行榜 | 总榜、歌曲热度/好评、谱师热度/好评，横向卡片与前50名；选歌看单曲榜 |
| 设置 | 文件夹引导置顶、两列操作卡片、QQ云同步、自动上传、头像/昵称/称号、谱库更新、JSON导出、诊断、获取更新 |
| 主题 | 浅色主题与各页面半透明角色背景 |

热度沿用服务器下载量统计：同歌谱面相加，谱师按作品汇总。谱师热度默认屏蔽列表由服务端维护，开启显示隐藏谱师后仍不显示 imddesigner。

模拟倍率、全图/单曲判定、准度和谱面等级只影响预览，不修改原始成绩、称号解锁或云端成绩。歌曲音频下载和预览按要求不提供。

## 云端与更新

与 Android 共用现有 QQ 成绩分片、v2 榜单、v1 兼容索引、键数补充、社区评论接口。上传不会删除原成绩分片或旧排行索引。读取失败时保留本地成绩；榜单有通过校验的离线缓存。兼容索引失败会单独提示，不把已成功的成绩上传误报为失败。

QQ 是存档编号，当前服务没有验证 QQ 归属，请勿填写他人的号码。昵称、头像、称号和目录授权保存在本机；评论会按玩家提交的昵称展示，成绩存档包含回放中的玩家名。目录授权、回放正文、服务器部署凭据不上传。

「获取更新」查询本仓库 iOS 发布包并打开发布页，下载后仍须自行签名。不能在 iOS 内安装 APK，也不直接安装未签名 IPA。

## 验证与构建

GitHub Actions 使用 macOS 执行核心测试、arm64 Release 构建、模拟器导入/去重/导航/歌曲筛选/布局测试。夹具为生成的虚拟谱面和回放，不使用玩家样本。运行时配置和素材来自已发布 Android 包，不提交服务器部署密钥或玩家目录快照。

本地 Windows 无法运行 Xcode。自签安装、真实回放判定、跨 App 目录授权持久性、相册与云端端到端上传仍需苹果真机测试；模拟器检查不代替这些验证。
